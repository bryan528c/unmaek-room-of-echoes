# 《언맥: 잔향의 방》

언령으로 전투 규칙을 바꾸는 2D 탑다운 액션 로그라이트입니다. Phaser 3, TypeScript, HTML/CSS, Web Audio API로 동작하며 백엔드나 런타임 외부 요청이 없습니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`, 순수 로직 테스트는 `npm run test`로 실행합니다.

## 조작

- `WASD` / 방향키: 이동, 메뉴 포커스 이동
- `J`: 자동 조준 대상을 향한 수동 단검 공격(길게 눌러 3연격 반복)
- `Tab` / `L`: 유효 자동 조준 대상 순환
- `K` / `Shift`: 패링
- `Space`: 무적 대시
- `Q`: 멎는다
- `E`: 되돌린다
- `R`: 잇는다
- `F`: 문장력 100일 때 다음 언령 강화 대기 / 다시 눌러 취소
- `Esc`: 강화 대기 취소, 일시정지, 메뉴 뒤로
- `1` / `2` / `3`: 강화 카드 즉시 선택
- `Enter` / `J`: 메뉴 확정
- 결과 화면에서 좌우 / `A` / `D`: 다시 시작과 타이틀 선택

키보드 전용이 기본입니다. 설정에서 기존 마우스 조준 방식으로 바꿀 수 있으며, 조작 모드가 없는 이전 저장 데이터에는 키보드 모드가 자동 적용됩니다.

## 언령 연쇄

첫 언령 뒤 2.5초 안에 유효한 두 번째 언령을 사용하면 두 번째 비용이 25% 할인되고 연쇄가 발동합니다.

- `R → Q` 연쇄 정지: 연결 대상과 그 탄환으로 정지가 전파됩니다.
- `Q → E` 역류: 멈춘 탄환을 원래 발사자 쪽으로 되돌립니다.
- `R → E` 피해 회귀: 연결 대상이 최근 2초 동안 받은 허용 피해의 30%를 재적용합니다.

## 개발 환경 도구

개발 서버에서만 사용할 수 있습니다.

- `F2`: 이동 충돌체, Hurtbox, Hitbox, 탄환 반경, Telegraph, 무적·패링·타깃 표시
- `F3`: 로컬 전투 통계 패널
- `F4`: 자동 조준, 판정, 세 연쇄, 보스 각 단계, 강화 지급 등을 위한 시나리오 메뉴
- `?qa=1`: 피해 없이 빠른 검증. `P`는 현재 전투 또는 보스 단계를 진행합니다.

설정과 최고 기록은 기존 키 `eonmaek-save-v1`을 유지한 채 localStorage에 저장됩니다. Combat Foundation v2 결정과 향후 작업은 [플레이테스트 백로그](docs/PLAYTEST_BACKLOG.md)에 정리되어 있습니다.
