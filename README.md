# 언맥: 잔향의 방

언령으로 전투 규칙을 바꾸는 2D 탑다운 액션 로그라이트입니다. 외부 서버나 런타임 네트워크 요청 없이 Phaser 3, TypeScript, HTML/CSS, Web Audio API만으로 동작합니다.

## 실행

```bash
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 엽니다. 배포용 빌드는 `npm run build`, 순수 로직 테스트는 `npm run test`로 실행합니다.

## 조작

- WASD / 방향키: 이동
- 마우스: 조준
- 마우스 왼쪽 / J: 단검 3연격
- 마우스 오른쪽 / K: 패링
- Space: 무적 대시
- Q: 멎는다
- E: 되돌린다
- R: 잇는다
- F: 문장력 100일 때 다음 언령 강화
- Esc: 일시정지
- Enter: 결과 화면에서 다시 시작

## 한 판의 흐름

세 번의 전투와 각 전투 뒤의 강화 선택을 거쳐 3단계 보스 `기록 포식자`와 싸웁니다. 승리 또는 패배하면 점수, 시간, 받은 피해, 패링, 언령 사용, 선택 강화와 랭크가 표시됩니다. 설정과 최고 기록은 브라우저 localStorage에 저장됩니다.

주인공은 제공된 콘셉트 시트의 초상·대기·이동·공격·시전 영역을 런타임에 투명 크롭해 사용합니다. 이미지 처리에 실패하면 같은 색상과 특징을 가진 절차적 저해상도 캐릭터로 자동 대체됩니다.
