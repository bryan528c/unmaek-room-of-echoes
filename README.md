# 언맥: 잔향의 방

언령으로 전투 규칙을 바꾸는 2D 탑다운 액션 로그라이트입니다. 외부 서버나 런타임 네트워크 요청 없이 Phaser 3, TypeScript, HTML/CSS, Web Audio API만으로 동작합니다.

## 실행

```bash
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 엽니다. 배포용 빌드는 `npm run build`, 순수 로직 테스트는 `npm run test`로 실행합니다.

## 조작

- WASD / 방향키: 이동
- J: 자동 조준된 적을 향해 단검 3연격(길게 눌러 반복)
- K / Shift: 바라보는 방향 패링
- Space: 무적 대시
- Q: 멎는다(자동 대상 또는 마지막 이동 방향 앞에 발동)
- E: 되돌린다
- R: 잇는다(자동 대상부터 주변 적을 연결)
- F: 문장력 100일 때 다음 언령 강화
- Esc: 일시정지
- 1 / 2 / 3: 강화 카드 즉시 선택
- WASD / 방향키 + Enter / J: 메뉴와 강화 카드 선택
- Enter: 결과 화면에서 다시 시작

기본값은 마우스 입력 없이 완주할 수 있는 `키보드 전용` 방식입니다. 설정에서 기존의 마우스 조준·클릭 공격 방식으로 전환할 수 있으며, 기존 저장 데이터는 자동으로 키보드 전용 기본값을 받습니다.

## 언령 연쇄

첫 언령이 성공한 뒤 2.5초 안에 다음 언령을 이으면 특별 효과가 발생합니다.

- 잇는다 → 멎는다: **연쇄 정지** — 연결된 대상과 그 탄환으로 정지가 전파됩니다.
- 멎는다 → 되돌린다: **역류** — 정지된 적 탄환을 감쇠된 피해로 되돌려 보냅니다.
- 잇는다 → 되돌린다: **피해 회귀** — 연결 대상이 최근 2초간 받은 직접 피해의 30%를 한 번 재생합니다.

강화 용언으로 첫 언령을 열어도 연쇄를 이어갈 수 있도록, 강화 언령 발동 뒤에는 후속 언령 1회에 충분한 문장력 35가 남습니다.

## 한 판의 흐름

세 번의 전투와 각 전투 뒤의 강화 선택을 거쳐 3단계 보스 `기록 포식자`와 싸웁니다. 승리 또는 패배하면 점수, 진행 단계, 이전 최고 기록과의 차이, 시간, 받은 피해, 패링, 언령 사용, 선택 강화와 랭크가 표시됩니다. 설정과 최고 기록은 브라우저 localStorage에 하위 호환 형태로 저장됩니다.

주인공은 제공된 콘셉트 시트의 초상·대기·이동·공격·시전 영역을 런타임에 투명 크롭해 사용합니다. 이미지 처리에 실패하면 같은 색상과 특징을 가진 절차적 저해상도 캐릭터로 자동 대체됩니다.

개발 서버에서 `?qa`를 주소 끝에 붙이면 검증용 단축키를 사용할 수 있습니다. `L`은 문장력과 언령 쿨다운을 초기화하고, `P`는 현재 전투 또는 보스 단계를 진행시킵니다.
