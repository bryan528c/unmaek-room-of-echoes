# 언령 시스템

## 장착과 입력

- 한 Run은 언령 6개 중 3개를 선택해 순서대로 Q/E/R에 장착한다.
- 기본 장착은 `멎는다 / 되돌린다 / 잇는다`이며 최근 구성을 로컬 저장한다.
- 장착은 Run 시작 시 고정되고 새 Run 전까지 바뀌지 않는다.
- 문장력 100에서 F를 누르면 다음 유효 언령 1회를 강화한다. 대상·회복·상태 효과가 모두 실패하면 문장력과 강화 대기를 보존한다.

## 전체 언령

| ID | 표시명 | 역할 | 기본 효과 | F 강화 |
|---|---|---|---|---|
| stop | 멎는다 | 공격·제어 | 범위 피해와 적·탄환 정지 | 범위·정지 시간 증가 |
| rewind | 되돌린다 | 방어·이동·공격 | 위치·체력 복구와 잔상 검격 | 복구·잔상 피해 강화 |
| link | 잇는다 | 관계·공격 | 최대 3대상 연결 또는 고립 연결 | 연결 수·공유 피해 증가 |
| pull | 당긴다 | 제어·이동 | 전방 소용돌이, 적 이동·탄환 굴절, 압축 | 범위 증가와 포획 탄환 방출 |
| mark | 새긴다 | 공격·관계 | 단일 각인, 직접 피해, 누적 폭발 | 최대 3대상, 각인 폭발 강화 |
| push | 밀어낸다 | 방어·이동·공격 | 부채꼴 충격파, 적 밀침·탄환 반사 | 360도 파동과 보스 취약 |

## 상태 태그

| 상태 | 표시명 | 기본 규칙 |
|---|---|---|
| STOPPED | 정지 | 멎는다 적용; 파쇄·역류 반응 대상 |
| ECHO / REWOUND | 잔향 / 회귀 | 되돌린다 잔상과 절단 재현 대상 |
| LINKED / ISOLATED | 연결 / 고립 | 공유 피해 또는 단일 피해 증폭 |
| PULLED / COMPRESSED | 끌림 / 압축 | 당긴다 이동·밀집 상태; 압축 반응 대상 |
| MARKED | 각인 | 직접 적중으로 스택 증가 후 폭발 |
| DISPLACED | 밀려남 | 밀어낸다 충돌·반동 사슬 대상 |
| EXPOSED / CUTTABLE | 노출 / 절단 가능 | 패링·보스 핵·봉합 갑주 절단 기회 |

상태에는 sourceWordId, duration, stacks, sourceEntityId, runId, actId, visualKey, 소비·전파·반응 가능 여부를 저장한다. 만료·대상 사망·Act 전환·새 Run에서 제거한다.

## 반응표

| 첫 언령 | 다음 언령 | 반응 | 핵심 결과 | 조건 부족 시 |
|---|---|---|---|---|
| 잇는다 | 멎는다 | 연쇄 정지 | 연결 대상 동시 정지·피해 | 단일 정지 파동 |
| 멎는다 | 되돌린다 | 역류 | 정지 탄환 역행 | 정지 대상 최소 파동 |
| 잇는다 | 되돌린다 | 피해 회귀 | 최근 직접 피해 재적용 | 최소 회귀 피해 |
| 당긴다 | 멎는다 | 압축 정지 | 압축 대상 정지·파열 | 소형 정지 파동 |
| 당긴다 | 잇는다 | 결속 | 밀집 대상을 자동 연결 | 단일 고립 연결 |
| 당긴다 | 밀어낸다 | 압축 폭발 | 바깥 폭발·충돌 피해 | 강화 압력파 |
| 새긴다 | 멎는다 | 봉인 문장 | 각인 폭발·정지 연장 | 최소 봉인 피해 |
| 새긴다 | 잇는다 | 각인 전염 | 연결 대상에 각인 전파 | 가장 가까운 대상 전파 |
| 새긴다 | 되돌린다 | 각인 회귀 | 각인 피해 재적용 | 최소 각인 회귀 |
| 멎는다 | 밀어낸다 | 정지 파쇄 | 정지 적 파쇄·탄환 반사 | 강화 충격파 |
| 밀어낸다 | 잇는다 | 반동 사슬 | 밀린 적 사이 연결·공유 | 짧은 고립 연결 |

## 카드 필터와 통계

- 보상 후보는 현재 장착 언령의 `requiredWordIds` 중 하나와 일치해야 한다.
- 범용·잔향 칼날·J 절단·패링·생존 카드는 장착과 무관하게 유지한다.
- 언령별 사용·직접 피해·F 사용, 반응별 사용·fallback·피해, 상태 적용, J 상태 반응 피해를 Run 통계로 보존한다.

## 안전 규칙

- 모든 반응·카드·공명 파생 피해는 중앙 DamageQueue를 통과한다.
- 최대 깊이 6, 루트당 파생 64, 프레임당 256을 넘는 이벤트만 차단한다.
- 공유·각인·충돌·포획·공명 피해는 같은 handler/대상 조합을 동일 계보에서 재실행하지 않는다.
- 모든 지연 효과는 runId와 actId가 현재 범위와 일치할 때만 실행한다.
