# 《언맥: 잔향의 방》 플레이테스트 백로그

상태 표기: `완료` / `진행 중` / `보류`

## 확정된 방향

| 상태 | 결정 |
|---|---|
| 완료 | 키보드 전용을 기본 조작으로 유지한다. |
| 완료 | 자동 조준과 수동 `J` 공격을 결합한다. |
| 완료 | 완전 자동 공격은 사용하지 않는다. |
| 완료 | 패링과 언령 연쇄를 전투 숙련의 중심에 둔다. |
| 완료 | 한 번에 사용하는 활성 언령은 `Q / E / R` 세 개다. |
| 완료 | 연쇄 정지, 역류, 피해 회귀의 세 연쇄를 유지한다. |

## Combat Foundation v2

| 상태 | 항목 | 검증 기준 |
|---|---|---|
| 완료 | 자동 조준 가독성·안정성 | 점수제 선택, 최소 유지시간, 교체 임계값, 3연격 잠금, `Tab / L` 순환 |
| 완료 | Hitbox / Hurtbox | 이동 충돌체·피해 범위·활성 공격 범위 분리, attackId 중복 적중 방지 |
| 완료 | 겹침 방지 | 플레이어-보스 강제 분리와 일반 적 사이 약한 분리 |
| 완료 | 렌더링 레이어 | Telegraph, Y-sort 캐릭터, 근접 효과, 탄환, 상태선, 전투 텍스트 순서 고정 |
| 완료 | 언령 연쇄 정착 | 25% 비용 할인, 원형 시간 게이지, 개별 사운드·피해 통계 |
| 완료 | 강화 용언 | 성공 시에만 소비, 취소 가능, HUD·캐릭터 준비 표시, 사용 통계 |
| 완료 | 강화 시스템 v2 | 기존 12개 감사, 행동 변화형 8개 추가, 태그 기반 카드 선택 |
| 완료 | 전투 통계 | 로컬 기록, F3 패널, 결과 화면 요약·상세 영역 |
| 완료 | 개발 도구 | 개발 빌드 전용 F2 판정, F3 통계, F4 시나리오 메뉴 |
| 진행 중 | 외부 플레이테스트 재검증 | 보스 60~90초 목표와 신규 강화 선택률을 실제 플레이 표본으로 확인 |
