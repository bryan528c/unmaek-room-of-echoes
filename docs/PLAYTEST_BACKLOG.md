## STABILITY-01R 리뷰 수정 기록

| 상태 | 항목 | 구현·검증 기준 |
|---|---|---|
| 완료 | 라운드 생존 집계 단일화 | `WaveDirector`가 pending spawn, 실제 전투 적 ID, spawn 완료, 320ms 안정 구간을 함께 검사하고 라운드 전환을 1회만 승인 |
| 완료 | stale registry 복구 | COMBAT에서 1.5초 동안 실제 적이 없으면 inactive·destroyed·누락 참조를 진단 후 정리하고, 살아 있는 경계 밖 적은 삭제 대신 전투장 안으로 복구 |
| 완료 | 사망 경로 통일 | 기본 공격, 패링, 언령, 연결, 피해 회귀, 넉백, QA 피해가 `Enemy.takeDamage` → 단일 death callback과 명시적 사망 원인을 사용 |
| 완료 | 패링 위치 고정 | 패링 활성·성공 구간의 플레이어 분리 이동을 차단하고 Ground Point를 복구. 적 보정은 프레임당 4px 이하, 공용 분리는 2.5px 이하로 제한하며 Sprite와 Physics Body를 즉시 동기화 |
| 완료 | J 임시 정상화 | 피해 `18/22/34 → 9/11/15`, 콤보 `480ms → 850ms`, 주 대상 100%·추가 대상 최대 2명 45%로 제한 |
| 완료 | 보스 결과 전환 | `BOSS_DEFEATED`에서 공격·탄환·입력을 정리하고 1.8초 사망 연출 뒤 결과를 1회만 확정 |
| 완료 | 자동 회귀 검증 | 30회 라운드 종료, 서로 다른 사망 원인, 중복 death, stale registry, 패링 위치, J TTK, 승패 동시 확정, 시간·입력 스트레스 단위 테스트 |
| 진행 중 | 외부 장시간 재검증 | 자동 10분/20회 가속 시뮬레이션 외에 실제 기기 10분 플레이와 20회 수동 재시작 표본 추가 확보 |
